# Run CivicFlow AI locally

1. Open this folder in VS Code.
2. Open Terminal in the project folder.
3. Run:

```bash
npm install
npm run dev
```

4. Open the Local URL shown by Vite, normally `http://localhost:5173/`.

The frontend intentionally uses plain CSS and React so it does not depend on Tailwind configuration. If you previously had a `node_modules` folder, delete it and run `npm install` again.
